// ABOUT

    
BUILT ON CIRCUITS.

          I am an Electrical & Electronics Engineering undergraduate at REVA
          University, Bangalore, working across the line where hardware ends and
          software begins. I write production-minded code in Java, C++, Python and
          TypeScript, and I build the systems around it — APIs, data models,
          interfaces and the analysis that proves they work.
        

        

          My work spans a full-stack website-abandonment detection platform, a
          PyTorch super-resolution model trained end-to-end without external APIs,
          an ADHD-friendly learning platform, and embedded fault-detection hardware
          built on Arduino. I co-authored an IEEE publication on the mathematical
          modelling and kinematic analysis of a 20-DOF humanoid robot.
